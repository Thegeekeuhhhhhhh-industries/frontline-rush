# Frontline Rush

A free 3D squad-runner for mobile. Steer your squad, shoot the gates to boost them, grab gun crates and take down the boss.

Made by **Thegeekeuhhhhhhh Industries** ([Thegeekeuhhhhhhh](https://www.thegeekeuhhhhhhh.dev)).

## Features

- One-finger controls: drag to steer, the squad fires automatically
- Gates that add, multiply or subtract soldiers, and that your shots can upgrade
- Enemy groups, weapon crates and a tougher boss every level
- Low-poly 3D graphics with [three.js](https://threejs.org/)
- Main menu and shop: bigger starting squad, better gun and squad colours
- Coins are earned by playing, with no real-money purchases
- Progress saved on the device (`localStorage`), no account and no data collected

## Tech stack

| Part | Technology |

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- [Android Studio](https://developer.android.com/studio) with the Android SDK, including the platform for API 36
- A phone with USB debugging turned on, or an Android emulator

### Install

```bash
cd src
npm install
```

### Play in your browser (quick testing)

```bash
cd src/www
npx serve .
```

Open the address it prints, ideally in your browser's mobile view.

### Run on Android

```bash
cd src
npx cap sync android # copies www/ into the Android project
npx cap open android
```

Then press the green **Run** button in Android Studio.

> Run `npx cap sync android` **every time** you change `www/index.html`. Otherwise Android Studio builds the old version.

If Gradle says *SDK location not found*, create `src/android/local.properties` with:

```
sdk.dir=C:/Users/<you>/AppData/Local/Android/Sdk
```

This file is specific to your computer and is not committed.

## Release build for Google Play

1. Set a unique `appId` in `capacitor.config.ts` and a matching `applicationId` in `android/app/build.gradle`. It cannot be changed after publishing.
2. Increase `versionCode` (and `versionName`) in `android/app/build.gradle` for every upload.
3. Check that `targetSdkVersion` and `compileSdkVersion` meet Google Play's current requirement.
4. In Android Studio: **Build → Generate Signed App Bundle / APK → Android App Bundle**, choose your keystore, then the **release** variant.
5. Upload the generated `.aab` in Google Play Console.

The `.aab` is created in `android/app/build/outputs/bundle/release/`.

**Never commit your keystore (`.jks`) or its passwords.** Back them up separately.

## Customising the game

Everything is in `www/index.html`:

- **Levels:** the `gen(L)` function (gate values, enemy health, boss health)
- **Balance:** `update(dt)` (fire rate, damage, speeds)
- **Shop:** `skins` and the `shop()` function (prices and limits)
- **Look:** `buildMeshes()` and `render()` for the 3D models and labels
